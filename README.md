# δ Хроно Варден - отдельный мод (Forge 1.20.1)

Независимый мод, не требует и не зависит от Δ: FOR THE DELTA. Свой modid `chronowarden`.

Активатор - ярко-голубая шестерня. Крафт: золото рамкой, часы сверху в центре, алмаз в центре
(или взять в креативе, вкладка «Инструменты и утилиты»). ПКМ призывает/убирает стенд.

Клавиши по умолчанию:
- K - Шар (тап = ур.1 просто взрыв, короткое удержание = ур.2 притягивает и взрывается, долгое = ур.3 маленький тайм-стоп)
- L - Якорь (1-й нажим ставит точку, 2-й откатывает и лечит; спасает от смерти один раз)
- P - Halt (замораживает мобов и снаряды перед лицом на 5 с)
- O - Тайм-стоп (замораживает всё вокруг на 5 с)

Все числа - в начале `ChronoManager.java`.

Сборка - как обычно: см. `КАК-ЗАПУСТИТЬ.txt`, через GitHub Actions, ничего локально ставить не надо.
